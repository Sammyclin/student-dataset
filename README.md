# CUL-CYB 371 – Data Mining and Data Warehousing
## Assignment Two: Fictional Student Dataset

### Project description
This project creates a fictional dataset containing 20 student records. It was prepared using Python and the built-in `csv` module.

### Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

### Files
- `create_dataset.py` – Python program that creates the dataset.
- `student_dataset.csv` – Generated dataset in CSV format.

### How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal or command prompt in this folder.
3. Run:

```bash
python create_dataset.py
```

The program creates `student_dataset.csv` in the same folder.

**Note:** All student information in this project is fictional and is used for academic purposes only.
